# CNN Fear & Greed 위젯

- **유형**: 개인 사이드 프로젝트 (대회·해커톤 아님)
- **트랙**: T6 빌드 (트랙 보드 반영은 월요일 회고 때)
- **대상 기기**: 갤럭시 (Android 8.0 이상)
- **배포**: 개인용 APK 직접 설치. Play 스토어와 공개 배포는 하지 않는다

## 현재 상태

> 세션을 끝낼 때마다 갱신한다. 월요일 회고가 여기를 읽는다.

- 마지막 작업일: 2026-10-31
- 진행: MVP 구현 완료. 단위 테스트와 에뮬레이터 검증은 가짜 서버로 통과. 실제 oanor API와 갤럭시 실기기는 미검증
- 다음 행동: oanor 가입과 키 발급 → 갤럭시에 APK 설치 → 키 입력 → 실제 값과 CNN 페이지 대조, 무료 한도 확인, 다음 평일 장중 갱신 확인

## 설치와 빌드

- APK: `outputs/fear-greed-widget-0.1.0-debug.apk` (Git 제외, `gradlew assembleDebug`로 재생성)
- 앱에서 API 키 입력 → "홈 화면에 위젯 추가" → 앱 정보 → 배터리 → "제한 없음"
- API 키는 앱 내부 저장소에만 두고, 저장소와 APK에는 넣지 않는다

## 아이디어

- **문제**: 시장 심리 지수를 보려고 매번 CNN 페이지를 열어야 한다
- **해결책**: 홈 화면 위젯에 점수, 등급, 게이지, 전일 대비, 갱신 시각을 보여준다
- **데이터**: oanor의 Stock Market Fear & Greed Index API (`x-oanor-key` 인증)

## 범위 (MVP)

- 반드시: 게이지 위젯, 미국 장 시간에 맞춘 갱신, 실패 시 마지막 값과 시각 표시, 앱 안에서 API 키 입력
- 있으면 좋음: 7개 세부 지표, 추이 그래프
- 하지 않음: 공개 배포, CNN 직접 조회, 투자 신호나 알림

## 갱신 정책

월 약 480회 사용. 미국 휴장일은 따로 구분하지 않는다.

## 데이터 출처의 한계

- oanor `/v1/meta`가 스스로 밝힌 원본은 CNN의 공개 피드(`production.dataviz.cnn.io`)다. CNN 라이선스를 보유했다는 언급은 찾지 못했다
- oanor 약관에는 개인 사용, 재배포, CNN 라이선스에 대한 내용이 없다
- 무료 한도: 가격표·`llms.txt`·OpenAPI는 월 12,000회, FAQ는 월 100회로 서로 다르다. 초과하면 429로 차단된다
