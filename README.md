# CNN Fear & Greed 위젯

- **유형**: 개인 사이드 프로젝트 (대회·해커톤 아님)
- **트랙**: T6 빌드 (트랙 보드 반영은 월요일 회고 때)
- **대상 기기**: 갤럭시 (Android 8.0 이상)
- **사용자**: 본인과 친구 2명. APK 직접 전달, Play 스토어와 공개 배포는 하지 않는다

## 설치와 빌드

- APK: `outputs/fear-greed-widget-0.4.0-debug.apk` (Git 제외, `gradlew assembleDebug`로 재생성)
- 앱 실행 → "홈 화면에 위젯 추가" → 앱 정보 → 배터리 → "제한 없음"

## 아이디어

- **문제**: 지수를 보려고 매번 Chrome에서 CNN 페이지를 열어야 한다
- **해결책**: 홈 화면 위젯에 점수, 등급, 게이지, 전일 대비, 기준 시각을 보여주고, 위젯을 탭하면 위젯별 디자인 설정을 연다. 원본은 설정 화면의 버튼으로 연다
- **데이터**: CNN 페이지가 쓰는 비공식 주소 (`production.dataviz.cnn.io/index/fearandgreed/graphdata`)

## 범위 (MVP)

- 반드시: 크기별 위젯, 미국 장 시간에 맞춘 갱신, 실패 시 마지막 값과 시각 표시, 위젯별 테마와 투명도 설정
- 하지 않음: 공개 배포, 브라우저 위장, 세부 지표와 추이 표시(원본에서 본다), 투자 신호나 알림

## 데이터 출처의 한계

- 공식 API가 아니고 문서도 없다. 주소나 응답 형식이 예고 없이 바뀔 수 있다
- 일부 요청은 418로 차단된다. 앱은 이름을 밝힌 User-Agent와 JSON Accept 헤더만 보내고, 브라우저로 위장하지 않는다
- 403, 418, 429를 받으면 위젯에 "CNN 접근 제한"을 표시하고 자동 조회를 6시간 쉰다. 통과 조건을 찾아 헤더를 바꾸지 않는다
- CNN 약관은 확인하지 못했다. 공개 배포하지 않는다
- 계속 차단되면 대안은 oanor API (`decisions.md` #1, #3 참고)
